# Calculadora de Vectores en Java

Una aplicación de calculadora de vectores desarrollada en Java con interfaz gráfica (GUI) usando Swing.

## Descripción
Este proyecto es una práctica de Programación Orientada a Objetos que permite calcular y visualizar operaciones con vectores bidimensionales.

## Características
- ✅ Suma de vectores
- ✅ Resta de vectores
- ✅ Multiplicación por escalar
- ✅ Cálculo de magnitud
- ✅ Interfaz gráfica amigable con Swing

## Requisitos
- Java JDK 8 o superior
- IDE como IntelliJ IDEA, Eclipse o NetBeans (opcional)

## Cómo ejecutar

### Opción 1: Desde línea de comandos
```bash
# Compilar
javac src/CalculadoraVectores.java

# Ejecutar
java -cp src CalculadoraVectores
```

### Opción 2: Desde un IDE
1. Abre el proyecto en tu IDE favorito
2. Navega a `src/CalculadoraVectores.java`
3. Haz clic derecho y selecciona "Run" o presiona Shift+F10

## Uso
1. Ingresa los valores para los vectores (X, Y)
2. Selecciona la operación que deseas realizar
3. El resultado se mostrará en la pantalla

## Ejemplo
- Vector 1: (1, 2)
- Vector 2: (3, 4)
- Operación: Sumar
- Resultado: (4, 6)

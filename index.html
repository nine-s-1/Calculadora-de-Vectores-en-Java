📐 Calculadora de Vectores

Interfaz gráfica en Java con Swing

✨ Características

  • Interfaz gráfica con Swing
  • Operaciones básicas con vectores
  • Botones simples e intuitivos
  • Panel para graficar vectores
  • Código limpio y compilable

📝 Código Java

import javax.swing.*;
import java.awt.*;

public class CalculadoraVectores extends JFrame {

    private JPanel panelGrafico;
    private JButton btnSumar;
    private JButton btnRestar;
    private JButton btnEscalar;
    private JButton btnBorrar;

    public CalculadoraVectores() {
        setTitle("Calculadora de Vectores");
        setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        setSize(600, 450);
        setLocationRelativeTo(null);
        setLayout(new BorderLayout(10, 10));

        // Espacio para graficar
        panelGrafico = new JPanel();
        panelGrafico.setBackground(Color.WHITE);
        panelGrafico.setBorder(BorderFactory.createLineBorder(Color.GRAY));
        add(panelGrafico, BorderLayout.CENTER);

        // Solo botones
        JPanel panelBotones = new JPanel(new FlowLayout());
        btnSumar = new JButton("Sumar");
        btnRestar = new JButton("Restar");
        btnEscalar = new JButton("Escalar");
        btnBorrar = new JButton("Borrar");

        panelBotones.add(btnSumar);
        panelBotones.add(btnRestar);
        panelBotones.add(btnEscalar);
        panelBotones.add(btnBorrar);

        add(panelBotones, BorderLayout.SOUTH);
    }

    public static void main(String[] args) {
        SwingUtilities.invokeLater(() -> {
            CalculadoraVectores ventana = new CalculadoraVectores();
            ventana.setVisible(true);
        });
    }
}

🚀 Cómo ejecutar

  1. Clona el repositorio: git clone https://github.com/nine-s-1/Calculadora-de-Vectores-en-Java.git
  2. Entra a la carpeta: cd Calculadora-de-Vectores-en-Java
  3. Compila el código: javac src/CalculadoraVectores.java
  4. Ejecuta el programa: java -cp src CalculadoraVectores
